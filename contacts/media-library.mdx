The media library is the workspace's own store of images, video, audio and documents. Upload something once and pick it wherever a file is needed, instead of uploading the same image into four different places.

Open **Media** from the sidebar.

## The library

Files are grouped into four tabs — **Image**, **Audio**, **Video** and **File** — each showing how many it holds. Anything that is not an image, audio or video lands under **File**, including PDFs and documents.

Within a tab, files you have used recently appear first under **Recently used**, then everything else. The search box filters by file name.

## Uploading

**Upload** takes one or more files at once. Each is limited to **16 MB**. After an upload the library switches to the tab your file landed in, so a new upload is never invisible because you were looking at another tab.

A meter on the right of the toolbar shows how much the workspace is storing, for example *"240 MB used of 1 GB"*.

<Note>
The 1 GB figure is advisory. It is there to measure against — nothing blocks an upload when you pass it.
</Note>

## Deleting

Select one or more files and use **Delete**. The confirmation says what it costs: anything already using the file will show a broken file, because the messages, templates and flows that reference it point at the file itself rather than holding a copy.

Deleting is permanent.

## Where the library is used

Four places pick from it, and all four see the same files:

- **The Inbox composer** — the paperclip menu's **From media library**. A file picked this way is sent as-is; discarding the draft does not delete the library file.
- **Template headers** — the image, video or document on a [message template](/whatsapp/templates).
- **Flow media nodes** — see [Node types](/flows/nodes).
- **Broadcast media** — see [Broadcasts](/whatsapp/broadcasts).

A picker is usually restricted to the kinds that make sense there, so a node that wants an image does not offer you a spreadsheet.

## What is not in the library

Files a customer sends you stay on their conversation and are not added to the library. Files you upload straight from the Inbox composer are attachments to that one message, not library entries — use **From media library** if you want to reuse a file.
